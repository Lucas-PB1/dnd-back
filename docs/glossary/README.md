# Glossário de termos traduzidos

**Versão:** 5.1.26

Tabela EN→PT da tradução comunitária (padrões 2014 e 2024).

## Arquivo de dados

- [`termos-traduzidos.json`](./termos-traduzidos.json) — 7146 entradas

Cada entrada:

```json
{ "pattern": "2024", "en": "…", "pt": "…" }
```

| Campo | Significado |
|-------|-------------|
| `pattern` | `2024` = Padrão Novo; `2014` = Padrão Velho |
| `en` | Termo em inglês |
| `pt` | Termo em português |

## Contagens

- 2024: 1201
- 2014: 5945

## Uso

Consulta humana ou scripts de alinhamento de nomes (spells/itens). **Não** é seed de runtime.

A planilha `.xlsx` original foi removida — o JSON é a SSOT neste repo.
